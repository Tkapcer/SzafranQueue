## Nazwa projektu: SzafranQueue
### Członkowie zespołu:
- Matylda Kołek,
- Paweł Gaj,
- Kacper Trólka.
### Wybrany język:
- Frontend: React Native (JavaScript),
- Backend: Laravel (PHP).
### Opis:
Celem aplikacji jest wspomaganie zarządzania salami ćwiczeniowymi w budynku uczelni muzycznej. Studenci korzystają z sal, by ćwiczyć grę na instrumentach (pianiści potrzebują sali z fortepianem), wykładowca korzysta z sal, by prowadzić w nich zajęcia, portier zarządza wydawaniem kluczy. System ma zapobiegać problemowi fizycznego czekania studentów w kolejce po sale i uporządkować sposób rezerwacji.
